# Project Instructions

## Project Background
- Local path: `/Users/zhaobingkun/dev/cluesbysam/cluesbysam.org`
- Live site: `https://cluesbysam.net/`
- This is a static SEO guide site for the daily logic puzzle game Clues by Sam.
- The local folder uses `.org`, but public URLs, canonical links, sitemap URLs, robots entries, contact email, and branding should use `.net`.

## Goals And Boundaries
- Keep the site crawlable as mostly static HTML.
- Preserve SEO basics on public pages: unique title, meta description, canonical, Open Graph/Twitter metadata where applicable, sitemap, robots, internal links, and readable on-page content.
- Do not make the site look official or imply affiliation with the original game developer.
- Keep homepage, archive pages, level pages, and blog pages easy to navigate from hubs.

## Work Rules
- Before project work, read `agents.md` and `memory.md`.
- Also check `PROJECT-MEMORY.md` when working on content imports, domain rules, homepage layout, or level data.
- Avoid switching `.net` references to `.org`.
- Use static HTML/CSS/JS patterns already present in the project unless there is a clear reason to introduce a new tool.
- When diagnosing live display issues, compare the live rendered page, live HTML, and local source.
- Record useful fixes, failures, and gotchas in `memory.md`.
